# CampusPath — Smart College Placement Frontend

Frontend-only React + Vite demo. The sidebar includes the requested SQL table names as individual pages: `department`, `student`, `resume`, `company`, `placement_drive`, `skill`, and `job_posting`.

## Run
1. Extract the ZIP.
2. Open the extracted `Smart_College_Placement_Frontend_Corrected` folder in VS Code.
3. Open a terminal in the same folder as `package.json`.
4. Run:
   ```cmd
   npm install
   npm run dev
   ```
5. Open the local URL Vite prints (usually http://localhost:5173/).

This is a frontend demo with sample data only. It does not connect to MySQL or require the SQL script to run.
